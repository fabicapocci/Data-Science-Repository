# Data Science & Machine Learning Portfolio

Hi, I'm Fabrizzio Capocci, a Computer Science student interested in data science, machine learning, and software development.

This repository contains data science and machine learning projects developed through coursework and refined for my portfolio. The projects demonstrate experience with data analysis, preprocessing, visualization, machine learning, and model evaluation.

## Projects

### 1. HR Job Change Classification

Built and evaluated multiple machine learning models to predict whether candidates are likely to seek a job change.

The project includes feature preprocessing, class balancing with SMOTE, dimensionality reduction with PCA, hyperparameter tuning, and comparison across multiple classification algorithms.

**Models:** Logistic Regression, KNN, Gaussian Naive Bayes, SVM, Decision Tree, Random Forest, AdaBoost, Gradient Boosting

**Best Overall Accuracy:** ~86% with Gradient Boosting

[View Project](./02-hr-classification/)

### 2. HR Analytics — Exploratory Data Analysis

Exploratory analysis of HR candidate data focused on understanding the dataset and identifying patterns relevant to candidate job-change behavior.

The project includes missing-value analysis, feature distributions, correlation analysis, outlier detection, categorical analysis, and feature engineering.

**Techniques:** Exploratory Data Analysis, Data Cleaning, Feature Engineering, Data Visualization, Correlation Analysis

### 3. Fake News Detection with NLP and Neural Networks

Applied Natural Language Processing techniques to classify news articles using their textual content.

The project compares Multinomial Naive Bayes with a Multi-Layer Perceptron neural network for fake-vs-real news detection and includes a separate multi-class experiment for predicting news subject categories.

**Models:** Multinomial Naive Bayes, Multi-Layer Perceptron (MLP)

**Techniques:** NLP, TF-IDF, Count Vectorization, Neural Networks, Multi-Class Classification

**Best Binary Classification Accuracy:** ~99.1% with MLP

[View Project](./03-deep-learning-nlp/)
